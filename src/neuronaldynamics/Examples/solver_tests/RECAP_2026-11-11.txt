2. COST (errors against the converged references; times with 4 runs in parallel)
- Heun costs 1.7-2.4x Euler per step. FPE timings in the old tables predate the compiled step: FPE now 0.4-0.7 s
  (1 pop) / 1-3 s (3 pop) on dv 0.1, dt 0.05 -> 60-170x faster than a 20k Heun network (old text: 7-20x).
- 1 pop: two-node FCT dt 0.05 (3 s) as accurate as a 20k-50k Heun network (33-118 s).
- 3 pop sigma 3.16: two-node FCT dt 0.05 (9 s) 0.6 % = 20k network (144 s).
- 3 pop sigma 1: best FPE 3.5-5 % (two-node, dt 0.01; dt 0.01 beating 0.005 in the step case is error cancellation),
  between a 5k and a 10k network at similar cost; in the 20 Hz case a 5k network (1.4 %, 32 s) beats every FPE.
- 2D + FCT: 10-20 min, worse than a 5k network in 5/6 cases; first-order closures 19-56 % (3 pop).
- 1 ms-bin L2 is meaningless for the sharp Heun bursts (20k vs 100k: 43 % with identical-looking rates); use smoothed.

3. CLOSURE DIAGNOSTICS (3 pop, sigma 1, step)
- All first volleys right; first wrong volley: exc 1 second volley (65.85 vs 66.16 ms, 2D 66.09); exc 2 and inh follow.
  inh has no adaptation -> error made in the adaptation of exc 1 between 30 and 66 ms.
- Not the top-moment closure: two-node c4 is 60-72 % off the 2D c4, Gaussian 1-31 %, yet both 1D closures give the
  same fields and the same error (0.124 / 0.122).
- 1D <u> of exc 1 is 1.0-1.3 pA below 2D at 35-55 ms (E[u|v] 0.5-1.9 pA below) -> more excitable -> early volley.
  But the 2D starts at <u> = +1 pA (initial mass in one u cell, cell centre) and its u remap broadens sd(u)
  (3.1 vs 1.4 pA before the first volley), so the 2D is not exact at the 1 pA level.
